/ → /en/根入口默认跳英文
  1. 确认申请

    确认个人／组织归属与博客名称，运维分配可用子域名。

  2. 部署并配置路径

    两套 Ghost 分别配置完整 /en/、/zh/ 公开 URL；代理按路径转发，根路径精确重定向 /en/。内部凭证由运维配置。

  3. 登记一个根地址

    自动派生两种语言地址，无需分别输入域名；实际平台根域名由部署配置决定。

  4. 三项独立结果

    英文、中文、根路径跳转分别核验。中文先就绪时，根入口仍等待英文，不自动改为中文。

  5. 完成或继续处理

    同址失败只重试对应项；改根地址须确认并重新核验全部。开通完成不等于发布授权，外发继续暂停。

真实核验需由 CMS 后端 API 执行。这里仅模拟状态与页面效果，未配置 DNS、代理、Ghost 或真实重定向。

站点与工作区

开通进度

补充资料、人工接单、逐站核验与失败恢复，都留在同一申请中。

04

05

一次登记根地址，分别核验两语言与根入口；根地址变更需重新核验。

06

07
