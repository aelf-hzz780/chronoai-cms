## 验证结果

- `node checks.cjs`：17 项状态回归通过。

- 两轮只读独立复核：第一轮聚焦任务／版本／副本，第二轮聚焦工作区／连接／公开站点／指标。已修复发现的撤权核验、错链接移除、重复副本、下线核验语义、异步导入归属、连接返回重放、关闭后 pending 和公开 owner 错配。

## 接口依赖与后续验收

下列为原型已展示、生产接入仍需确认的依赖：

1. NyxID → CMS 的可信回程、owner/指定账号绑定、状态重查；当前业务配置文件路径不能被视作动态绑定 API。
2. 当前组织的成员目录和 `canManagePublishers` 能力；不能从 `canPublish` 推断 Admin。
3. 真实私有素材上传、Ghost 图片转存和补图幂等性；原型 Blob URL 不跨刷新。
4. 延迟待办的持久化及到期提醒。自动调度是后续可选项。
5. 原文已变化或下线后的人工既有副本认回：普通 report 仍受原文前置条件约束；原型单独标注只读核验交互，需要独立服务端合同，不能直接复用 report 假定已支持。
6. 外部累计指标的采集快照与覆盖范围、Ghost 区间聚合、部署隐私配置。原型不发统计事件。

下一阶段应按以上合同接入并验收。关键指标是完成“保存 → 确认 → 原文 → 分发核验”的成功率和时间；保护指标为误发／重复副本数、跨 owner/语言误用数、未知结果重发数、未经许可的读写和统计次数，目标均为 0。

生产接入属于后续工作：建议沿用三个包逐步接入，用 feature flag 保留旧界面回退，并分别验证数据兼容、权限与发布副作用。此轮没有上线动作，无须改变当前业务运行状态。
