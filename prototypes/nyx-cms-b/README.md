## 三种语言选择

- **CMS 界面语言**：默认 English，支持简体中文；切换只更新 UI，不重建表单，不改变文章正文、未保存输入、选中文件、任务、权利勾选或发布目标。
- **文章语言**：编辑器 EN／中文对应两篇关联稿件，草稿、提交、修订和公开状态分别管理；只发布当前语言。
- **公开阅读语言**：切换对应语言的公开站点；公开页面 UI 跟随阅读语言，返回 CMS 恢复界面偏好。
- **两个 Ghost**：每 publication × language 一个 Ghost。当前每工作区展示一个双语 publication；组织、个人和另一个组织各有一个平台子域名，使用 `/en/` 和 `/zh/` 路径。根路径默认英文。本地 hash 路由模拟跨站浏览。

## 推荐体验路径

1. **内容库 → 待发布**：`permissions` 的 EN 是已提交，ZH 是已公开；两种状态不会互相覆盖。
2. **编辑器 → 保存 → 私有预览 → 发布确认**：输入自己的 Markdown 或插入本地 PNG/JPEG/WebP，检查预览与确认内容一致；确认后立即切到「发布与分发」，任务仍会继续。
3. **文章分发详情 → DEV 查看任务**：模拟精确批准后执行；完成后显示「纠错现有副本」「人工移除副本」，保持同一已知副本身份。所有链接都标为样例。
4. **连接与渠道 → 管理连接**：演示未绑定、账号不匹配、取消与恢复。恢复不会重置任务或重发内容。
5. **Medium 查看任务 → 记录人工跟进**：提交、审核、拒绝分别记录；公开需平台链接和来源核验。原文已变化时可进入独立“核验既有公开副本”，标记后续纠错／移除。
6. **场景演示**：选择多个组织、组织加载失败、Member／Admin、成员保存失败、GPC/DNT，以及下一次原文／分发结果。
7. **补图**：在编辑器插入图片并保存；场景中选择「已公开但图片待补齐」后发布；到「发布与分发」点击「补齐公开图片」，确认版本和图片权利。
8. **数据分析**：切换 Ghost、DEV、Hashnode 及时间窗口，观察累计值不按天数缩放；Hashnode 评论不可用，反应为真实样例 0。
9. **公开博客**：拒绝或允许当前语言站点统计，切换另一语言后单独选择；底部可以撤回。
